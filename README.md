# Discovery Camp — Telegram check-in bot

Чек-ін через QR-код → Telegram, відмітка в Google Sheets, відеопривітання від лідера команди, реєстрація на події та ранкові нагадування. Хоститься на Vercel (serverless + cron).

## Як це працює

1. На вході висить плакат із QR-кодом (`npm run qr`). Він відкриває бота: `t.me/<bot>?start=checkin`.
2. Відвідувач пише своє прізвище та ім'я → бот шукає його у вкладці з відповідями форми → показує кнопки зі збігами.
3. Після підтвердження бот записує Telegram ID і час чек-іну в таблицю та надсилає відео лідера команди.
4. Далі бот знає людину назавжди: `/events` (реєстрація на події дня), `/schedule`, `/myevents`, ранковий дайджест о 8:00 за Києвом.

## Налаштування

### 1. Бот

- Створіть бота через [@BotFather](https://t.me/BotFather) → отримайте `BOT_TOKEN`.
- Дізнайтесь свій Telegram ID (наприклад, через @userinfobot) → `ADMIN_IDS`.

### 2. Google Sheets

- У [Google Cloud Console](https://console.cloud.google.com) створіть проєкт → увімкніть **Google Sheets API** → створіть **Service Account** → згенеруйте JSON-ключ.
- З ключа візьміть `client_email` → `GOOGLE_SERVICE_ACCOUNT_EMAIL` і `private_key` → `GOOGLE_PRIVATE_KEY`.
- **Поділіться таблицею** з email сервісного акаунта (роль Editor).
- `SHEET_ID` — це частина URL таблиці між `/d/` і `/edit`.

У таблиці:

- **Вкладка з відповідями форми** (`RESPONSES_TAB`): додайте праворуч дві колонки з заголовками `Checked in` і `Telegram ID`. У `NAME_HEADER` вкажіть точний текст питання з ПІБ. Якщо є колонка з командою — вкажіть її заголовок у `TEAM_HEADER`.
- **Вкладка `Events`** з заголовками: `ID | Date | Time | Title | Capacity`
  - `Date` у форматі `2026-07-13`, `Capacity` = 0 — без обмежень. `ID` — будь-який унікальний (e1, e2…).
- **Вкладка `EventRegs`** з заголовками: `Event ID | Telegram ID | Name | Registered at | Cancelled at` (бот заповнює сам).
- **Вкладка `Videos`** (необов'язково): `ID | Team | File ID | Type` — відео для кожної команди. `ID` — числовий, незмінний ключ (1, 2, 3…); `Team` — назва команди (можна перейменовувати); `Type` — `video_note` або `video`. Значення `ID` у цій вкладці має збігатися зі значенням колонки `Команда` у відповідях форми та в колонці `Team` у вкладці `Leaders`.
- **Вкладка `Admins`**: `Telegram ID | Name` (бот заповнює через `/addadmin`).
- **Вкладка `Leaders`**: `Team | Name | Telegram ID | Linked at` (бот заповнює через `/addleader`). Колонка `Team` містить числовий ID команди.

### 3. Деплой на Vercel

1. На [vercel.com](https://vercel.com) → **Add New Project** → імпортуйте репозиторій з GitHub.
2. У **Settings → Environment Variables** додайте всі змінні з `.env.example`.
3. Vercel задеплоїть проєкт автоматично. Надалі кожен пуш у `main` → автодеплой.

Після першого деплою зареєструйте webhook (один раз):

```bash
cp .env.example .env   # заповніть VERCEL_URL та інші значення
npm run set-webhook
```

Webhook залишається дійсним для всіх наступних деплоїв — URL не змінюється.

### 4. Відео лідерів

Лідер надсилає відео або відеоповідомлення (кружечок) боту — бот автоматично зберігає його у вкладку `Videos` для своєї команди. Адміністратор отримує `file_id` для ручного використання. Якщо відео одне для всіх — вкажіть `DEFAULT_VIDEO_FILE_ID` у змінних оточення.

### 5. QR-код для плаката

```bash
npm run qr   # створює checkin-qr.png (потрібен BOT_USERNAME у .env)
```

## Команди бота

Відвідувачі й лідери використовують кнопки постійної клавіатури; команди нижче потрібні переважно адмінам.

| Команда | Роль | Опис |
|---|---|---|
| `/start` | всі | чек-ін або відновлення клавіатури |
| `/events` | всі | події на сьогодні + реєстрація |
| `/schedule` | всі | розклад на всі дні |
| `/myevents` | всі | мої реєстрації |
| `/notifyteam <текст>` | лідер | розсилка учасникам команди |
| `/renameteam <назва>` | лідер | перейменувати команду |
| `/addleader <ID> <ПІБ>` | адмін | додати лідера (`ID` — числовий ID команди) |
| `/removeleader <ID> <ПІБ>` | адмін | видалити лідера |
| `/listleaders` | адмін | список лідерів |
| `/broadcast <текст>` | адмін | розсилка всім учасникам |
| `/addadmin <TelegramID> <ім'я>` | суперадмін | додати адміна |
| `/removeadmin <TelegramID>` | суперадмін | видалити адміна |
| `/listadmins` | суперадмін | список адмінів |

## Нотатки

- Ранковий дайджест: cron у `vercel.json` (`0 5 * * *` UTC = 8:00 Києва влітку).
- Ліміт місць перевіряється при реєстрації; за одночасних кліків теоретично можливий незначний перебір — для табору це прийнятно.
- Telegram-розсилки йдуть послідовно; для кількох сотень учасників вкладається в 60 с cron-функції.
